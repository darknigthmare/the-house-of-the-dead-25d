## Réserves et traçabilité

Les 16 appels ImageGen ont produit 14 sorties retenues pour le jeu. Deux sorties sont écartées de la galerie : première arme de James et premier Brutus avec contamination du tatouage par le réticule HUD. Les versions corrigées sont livrées. La première image de James est conservée uniquement dans les références documentaires comme entrée exacte de l’édition ; le rejet Brutus reste hors dépôt. Cet intermédiaire ne compte pas parmi les 14 PNG de production ni les 379 chemins PNG sous assets/dossier_curien. Aucun PNG historique n’est remplacé.
