## Sources documentaires

- [SEGA — Zombie Revenge, manuel Dreamcast](https://www.digitpress.com/library/manuals/dreamcast/zombie_revenge.pdf) : Le manuel décrit la tenue 2 Player accessible avec Start en Arcade Mode et une troisième tenue avec Start+Y en Original Mode. Cela atteste le mécanisme général, pas la géométrie exacte de chacun des six rendus ni l’exhaustivité de toutes les variantes régionales.
- [Greg Kramer — Prima’s Official Strategy Guide: Zombie Revenge](https://archive.org/details/zombie-revenge-prima-guide) : La section objets décrit ARMOR comme une protection temporaire, avec une icône. Le passage ne suffit pas à établir que ce bonus et le modèle rouge du troisième costume sont la même mécanique ; le lot ne les confond pas.
- [GameSpot — Zombie Revenge Review, 2000](https://www.gamespot.com/reviews/zombie-revenge-review/1900-2540798/) : Le test décrit une armure liée à un objet et à la prise de dégâts. Cette description et l’identification communautaire du modèle rouge comme troisième tenue ne sont pas fusionnées en une affirmation mécanique certaine.

## Recherches qui n’ont pas levé les réserves

La [galerie du site officiel Dreamcast archivé](https://web.archive.org/web/20030409235203fw_/http://zombie-r.dricas.ne.jp/jp/gallery.html) a été parcourue. Le portrait de Linda récupéré est un portrait standard de buste ; il n’atteste pas les chaussures des tenues alternatives. Plusieurs pages ou images suivantes sont absentes des captures accessibles. Ce portrait n’a pas été envoyé au générateur.

La courte vidéo [Change Costumes](https://www.youtube.com/watch?v=CcjSLWIIcbQ) montre un écran filmé et reste trop petite pour la géométrie. Les vidéos Original Mode [Bare Knuckle](https://www.youtube.com/watch?v=7I8T90Ceig4) et [Gun Mode](https://www.youtube.com/watch?v=3XUafCyj1bE) inspectées montrent des tenues standard dans les vues récupérées. Elles ne sont pas utilisées pour reconstruire les variantes cuir. Les fichiers de recherche exploratoires restent hors de cette livraison.

## Intégrité

Le fichier [source_index.json](source_index.json) et le reçu listent les SHA-256 des dix fichiers de référence locaux : six WEBP, deux storyboards JPEG et deux découpes PNG. Les originaux téléchargés sont inchangés ; les deux découpes sont les seuls traitements de référence, sans rééchantillonnage. Aucun pixel des six images générées n’a été modifié avec un outil local.

Le style est fourni par [isaac_guard.png](../../../../../assets/dossier_curien/saga/isaac_guard.png), déjà présent dans le projet. La sortie initiale rejetée de Rikiya est identifiée par son nom natif et son hash dans le reçu ; elle n’est pas faussement déclarée comme fichier de référence présent dans le dépôt.
